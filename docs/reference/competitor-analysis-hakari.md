# oma-hakari.framer.website: what was taken and what wasn't

Hakari is a Framer *template* ("Creative Social Media Marketing Agency"). Its copy is placeholder text (the hero line, "300+ clients", "$80M+ revenue", fake campaign stats, pricing, a blog). None of that is reused: Zocial has no such claims to make.

## Read from the page
- Type: **Anton** for headlines (66px/69px, all caps), **Inter / Inter Tight** body, **Geist Mono** for small bracketed labels (`[ WHO WE ARE ]`).
- Palette: near-black `#1a1a1a` / `#2c2c2c`, white, light greys `#f5f5f5` / `#ebebeb`, one loud accent (orange `#ff5b03`) used only for buttons.
- Structure: floating pill nav (logo left, accent CTA right) -> hero with a pill badge, giant caps headline, filled + outline CTA, logo strip, a huge rounded hero photo, and a few floating platform icons (YouTube, TikTok, LinkedIn, Instagram) tilted around the headline -> orange full-bleed band -> big uppercase statement in low-contrast grey -> 4 benefit blocks (reach, impact, authority, speed) -> numbered campaign cards with a count-up stat row and a big rounded photo -> pricing toggle -> testimonial -> services accordion -> blog -> FAQ.

## Adopted here (so it reads as a studio, not a template)
- **A few platform badges, not a wall of social logos**: Instagram, YouTube and Facebook float around the hero eye (`.hero-socials`). Only Instagram is a link, because it is the only profile that exists. The footer lists Instagram only.
- Bracketed small labels and an accent colour reserved for buttons, cards and the eye.
- Real photography instead of illustration: the "Who will you cooperate with" cube now carries four web photos (film crew, stabiliser rig, a red-lit edit desk, a strategy wall of sticky notes) with a caption chip each.
- Plain-language copy. The brochure lines ("award-winning powerhouse", "world class team") were left out; copy states what is true: a small crew, a six-step process, real posts.

## Deliberately not adopted
- Pricing, blog, fake client logos, invented revenue/ROI numbers, "best agency 2025" badge. Add them only when they're real.
